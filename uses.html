The gear behind the builds

Uses

Everything I build and tinker with runs on this stack. Updated as the lab evolves — see the homelab diary for the ongoing story.

Homelab

  • Edge: ISP gateway feeds a Deco mesh, then a FortiGate, then a Palo Alto PA-440 — firewalls in series, lab behind both.
  • Compute: two Proxmox mini-PCs — Ryzen 7 4800H (16c / 32 GB) and Ryzen 7 5700U (16c / 62 GB). Mostly game servers today; a k3s cluster is next.
  • Switching: Cisco 1G PoE switch plus a couple of TP-Link managed switches.
  • Cloud watcher: a small Hetzner VPS in Ashburn running Uptime Kuma — monitoring lives outside the lab's failure domain on purpose.
  • Remote access: Tailscale everywhere. No inbound port forwards, ever.

Desk

  • Gaming PC (Windows 11): RTX 4080 16 GB — doubles as a local LLM box via Ollama (gpt-oss-20b fits comfortably).
  • Work MacBook: work-issued and off-limits for personal projects. Heavy corporate security, zero exceptions.

Software I reach for

  • Proxmox VE for virtualization, Docker Compose for services, Tailscale for connectivity.
  • GitHub Pages hosts all eleven sites; deploys are single-commit pushes, changelogs mandatory.
  • Umami (cookieless) for analytics — no consent banners.
  • Suno for the AI band, Spotify for everything else.

Currently learning

  • Terraform + k3s — the homelab Kubernetes track, documented as I go.
