Copy-paste workflows

Install a workflow with one paste.

Each prompt below installs a real workflow into any AI assistant — the same ones running this site's daily pipeline. No accounts, no API keys, no setup docs. Every prompt is tested: paste it into a fresh chat and it works. Every prompt ships with its safety checklist, stated up front.

The pattern is borrowed from Skill Harbor; the bar is higher here — tested prompts, and safety checks that are real.

Workflow 01

Daily SE Briefing

The workflow behind the SE Command Center's morning briefing: research seven vendors overnight, keep only what's usable in a customer conversation, format it for a presales engineer, and flag what's unverified.

The install prompt

Install the "Daily SE Briefing" workflow in this chat. Each run: 1. Research the last 24 hours of news for: Dell, Cisco, CrowdStrike, VMware/Broadcom, Cohesity, Palo Alto Networks, Nutanix. 2. Keep only what a presales systems engineer can use in a customer conversation: product launches, CVEs, competitive moves, pricing/licensing changes. No filler, no press-release rewrites. 3. Format each item as: headline, 2-3 sentence summary, "why it matters" (one line for a customer call), source link. 4. End with an "Honest caveats" block: what wasn't verified, what's vendor-claimed vs independently confirmed. SAFETY CHECK — before the first run, confirm: - You will only read public sources. You won't touch my accounts, inbox, or files. - If any step needs credentials or private data, stop and ask me first.

Paste into any fresh assistant chat to install the workflow.

Safety check

  • ('Public sources only. The workflow reads the open web — never your accounts, inbox, or files.', 'Stop on credentials. If any step needs a login, API key, or private data, it asks you first instead of improvising.', 'Caveats are mandatory. Every briefing ends with an honest-caveats block: vendor-claimed vs independently confirmed.')

How to use

1. Copy the prompt, paste it into a fresh chat with your AI assistant, and confirm the safety check. It runs the briefing from there.

Workflow 02

Daily Tech News Podcast

The pipeline behind the Daily Tech News podcast: pick the 4–5 stories that matter, write a two-host script for Alex and Jordan, keep it tight, and mark rumor vs confirmed.

The install prompt

Install the "Daily Tech News Podcast" workflow in this chat. Each run: 1. Pick the 4-5 most interesting tech stories from the last 24 hours — datacenter, AI, and infrastructure first. 2. Write a conversational two-host script (Alex: warm and curious, Jordan: dry and technical). Vary the cold open every day — never ship formulaic, interchangeable episodes. 3. Keep it to about 8 minutes of spoken audio. End with one takeaway per story. 4. Append "Honest caveats": which stories are single-sourced, what's rumor vs confirmed. SAFETY CHECK — before the first run, confirm: - You won't publish or upload anything. Script only; I handle recording and posting. - If a story involves a security vulnerability, include the vendor's patch guidance, not exploit detail.

Paste into any fresh assistant chat to install the workflow.

Safety check

  • ('Script only, never publish. The workflow writes the script — recording, uploading, and posting stay in human hands.', "No exploit detail. Vulnerability stories get the vendor's patch guidance, not how-tos.", 'Fresh every day. The cold open and segment order vary per episode — no formulaic, interchangeable output.')

How to use

1. Copy the prompt, paste it into a fresh chat with your AI assistant, and confirm the safety check. It drafts the episode from there.

Workflow 03

Daily Song Picks

The morning music routine: three new songs in the Bilmuri / A Day To Remember lane, one line on why each fits, and what to listen for — without ever touching your existing playlists.

The install prompt

Install the "Daily Song Picks" workflow in this chat. Each run: 1. Find 3 new songs I haven't heard. Lean into my lane: Bilmuri / A Day To Remember territory — pop-punk-infused metalcore, emo, genre-fluid heavy pop — at least 1-2 of the 3. The third can be heavier straight metalcore. 2. For each: song — artist, one line on why it fits, and what to listen for (a riff, a drum fill, a vocal moment). 3. Skip anything already on my Muse playlists. No repeats across days. SAFETY CHECK — before the first run, confirm: - You'll never delete songs from my existing playlists — only add to the Muse-created ones. - Recommendations only. You won't play, buy, or stream anything.

Paste into any fresh assistant chat to install the workflow.

Safety check

  • ('Your playlists are read-only. The workflow never deletes from existing playlists — it only suggests additions for the Muse-created ones.', "Recommendations only. It won't play, buy, or stream anything on your behalf.", 'No repeats. It skips anything already on your Muse playlists and avoids repeating itself across days.')

How to use

1. Copy the prompt, paste it into a fresh chat with your AI assistant, and confirm the safety check. Tell it your lane if yours differs.
