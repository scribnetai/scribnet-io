Install a workflow with one paste.

Each prompt below installs a real workflow into any AI assistant — no accounts, no API keys, no setup docs. Every prompt opens with a short setup interview (up to five questions, one at a time), so the workflow configures itself to your world: your topics, your show, your taste in music. Every prompt is tested from a fresh chat, and every prompt ships with its safety checklist, stated up front.

The standard is simple — tested prompts, setup that adapts to you, and safety checks that are real.

Workflow 01

Daily Briefing

Your morning briefing, on your beat. Tell it your topics, companies, or industries — it researches the last 24 hours, keeps only what you can actually use, and flags what's unverified.

The install prompt

Install the "Daily Briefing" workflow in this chat. SETUP — first run only. Ask me these one at a time (max 5 questions). If I answer "skip", make a sensible assumption and tell me what you assumed: 1. What should the briefing cover? (topics, companies, or industries — up to 7; e.g. "electric vehicles, Tesla, Rivian, battery tech") 2. What do you do, and what makes a story useful to you? (so I keep signal, not trivia) 3. How long should it be — a 5-minute scan or a 15-minute read? 4. Anything to always leave out? (e.g. funding rounds, rumors, press-release rewrites) EACH RUN: 1. Research the last 24 hours across the topics above. First, say whether you can access current web sources in this chat. If you cannot, say so plainly — run it from background knowledge and label every item "unverified in this session". 2. Keep only what the person in setup Q2 can actually use. Cut filler. 3. Format each item: headline, 2-3 sentence summary, one line on "why it matters to you", source link. 4. End with "Honest caveats": what's single-sourced, what's vendor-claimed vs independently confirmed, what you couldn't verify. HARD RULES: - Mark anything you cannot find as NOT FOUND instead of guessing. - Never invent citations, quotes, statistics, or dates. - Keep every summary under 60 words. SAFETY CHECK — confirm before the first run: - You will only read public sources. You will not touch my accounts, inbox, or files. - If any step needs credentials or private data, stop and ask me first.

Paste into any fresh assistant chat to install the workflow.

  • What do you do, and what makes a story useful to you?
  • A 5-minute scan or a 15-minute read?

  • ('Public sources only. It reads the open web — never your accounts, inbox, or files.', 'Stop on credentials. Workflow 02

Podcast Script Studio

A two-host show from yesterday's news. You define the topic, the hosts, and their personalities — it picks the stories, writes a conversational script that actually sounds like them, and marks rumor vs confirmed.

The install prompt

Install the "Podcast Script Studio" workflow in this chat. SETUP — first run only. Ask me these one at a time (max 5 questions). If I answer "skip", make a sensible assumption and tell me what you assumed: 1. What's the show about, and who's listening? (topic focus + target audience) 2. Who are the hosts? Two names, one-line personality each (e.g. "Maya: warm and curious; Dev: dry and technical"). 3. How long is an episode? (e.g. "about 8 minutes of spoken audio") 4. Tone guardrails — anything off-limits or must-avoid? EACH RUN: 1. Pick the 4-5 most interesting stories in the show's focus from the last 24 hours. 2. Write a conversational two-host script with the hosts from setup. Vary the cold open and segment order every run — never ship formulaic, interchangeable episodes. 3. Fit the episode length from setup. End each story with one takeaway. 4. Append "Honest caveats": which stories are single-sourced, what's rumor vs confirmed. HARD RULES: - Every line must sound like its speaker — if a line could come from either host, rewrite it. - Never invent quotes or statistics. Flag unverified claims in the caveats block. SAFETY CHECK — confirm before the first run: - Script only. You will not publish, upload, or schedule anything — I handle recording and posting. - If a story involves a security vulnerability, include the vendor's patch guidance, not exploit detail.

Workflow 03

Music Discovery

New songs in your lane, on repeat. Name your reference artists or describe the sound — it hunts down tracks you haven't heard, tells you why each fits, and what to listen for.

The install prompt

Install the "Music Discovery" workflow in this chat. SETUP — first run only. Ask me these one at a time (max 5 questions). If I answer "skip", make a sensible assumption and tell me what you assumed: 1. What's your lane? Name up to 3 reference artists, or describe the sound (e.g. "pop-punk-infused metalcore, emo"). 2. What are you hunting — brand-new releases, deep cuts you missed, or both? 3. How many picks per run? (default: 3) EACH RUN: 1. Find N songs the listener likely hasn't heard, anchored in the lane from setup. 2. For each: song — artist, one line on why it fits, and what to listen for (a riff, a drum fill, a vocal moment). 3. No repeats: keep a running list in this chat of everything recommended and never repeat an item. HARD RULES: - Do not invent song titles, artists, albums, or release years. Omit anything you cannot verify. - If you can't verify a track exists, drop it and pick another — never pad the list. SAFETY CHECK — confirm before the first run: - Recommendations only. You will not play, buy, or stream anything. - You will never modify any playlist — you suggest; the listener adds.

Paste into any fresh assistant chat to install the workflow.

First-run setup

The prompt interviews you before the first run — up to five questions, one at a time. Say "skip" any time; it states its assumptions aloud.

  • What's your lane? (up to 3 reference artists, or describe the sound)
  • New releases, deep cuts, or both?
  • How many picks per run?

Safety check

  • ("Recommendations only. It won't play, buy, or stream anything on your behalf.", 'Your playlists are read-only. It suggests; you add. Nothing gets modified.', "No invented tracks. If it can't verify a song exists, it drops it and picks another — never pads the list.")

How to use
